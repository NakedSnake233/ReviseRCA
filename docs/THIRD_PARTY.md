# Baseline provenance and scope

The published comparisons use the local source-guided adapters in
`src/dyrca_rca/baselines/methods.py`, not unmodified upstream pipelines. NSigma,
BARO, CIRCA, CloudRanger, Eadro and HolisticRCA share the supplied dynamic evidence
and candidate inventory. Native modality pipelines and graph discovery are not
reproduced in full. `baselines/dyrca_baselines/` is an older adapter implementation;
use the `src/` implementation for the current comparison.

Upstream checkouts consulted locally (not redistributed here):

Consult each upstream repository for its own license and citation requirements.
The local implementation does not require cloning these repositories. Older
optional PyG data-export helpers require `torch_geometric`; the current plain
PyTorch smoke and test workflow does not.

CloudRanger in this code snapshot uses a fixed seed, independent of case names.
Historical frozen results used an earlier identifier-dependent seed. The behavioral
extension uses the corrected implementation; do not expect the current adapter to
recreate that historical implementation's exact random walks.

The Train Ticket deployment script downloads FudanSELab/train-ticket on explicit execution. Generated `.manifests/` files are excluded; they are regenerated by the deployment script.
